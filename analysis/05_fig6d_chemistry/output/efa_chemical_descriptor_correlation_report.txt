EFA vs non-DFT chemical descriptors: calculation report
==============================================================================

1. Purpose
   This analysis quantifies how non-DFT chemistry descriptors relate to the
   entropy-forming ability (EFA).

2. Input data
   Input workbook: analysis/05_fig6d_chemistry/input/locked_493.xlsx
   Sheet: combined
   Rows used after dropping missing EFA: 493
   Non-DFT chemistry descriptor range: Excel columns S:AK
   Number of chemistry descriptors analyzed: 19

3. Target
   EFA: entropy-forming ability, plotted as EFA

4. Heatmap focus descriptors
   VEC -> VEC
   delta_electronegativity_Ghosh -> $\delta\chi_{\mathrm{Ghosh}}$
   delta_radii_Ghosh08 -> $\delta r_{\mathrm{Ghosh}}$
   delta_radius_PT -> $\delta r_{\mathrm{PT}}$
   param_geo_radii_Ghosh08 -> $\Lambda_{\mathrm{Ghosh}}$
   param_geo_radius_PT -> $\Lambda_{\mathrm{PT}}$

5. Calculation procedure
   a) Read the input workbook and select non-DFT chemistry descriptors from S:AK.
   b) Convert EFA and descriptor columns to numeric values.
   c) For every target–descriptor pair, calculate Pearson and Spearman correlations.
   d) For each target and method, apply Benjamini-Hochberg FDR correction across all S:AK descriptors.
   e) Rank descriptors by absolute correlation coefficient for each target and method.
   f) Store all long-form results, heatmap matrices, FDR matrices, and plot-data columns in Excel.

9. Interpretation
   Positive correlations with EFA indicate chemistry descriptors that increase with entropy-forming ability.
   The heatmap focuses on chemically interpretable descriptors: VEC, Ghosh electronegativity mismatch,
   Ghosh and Pauling/periodic-table radius mismatch, and the corresponding Λ parameters.
