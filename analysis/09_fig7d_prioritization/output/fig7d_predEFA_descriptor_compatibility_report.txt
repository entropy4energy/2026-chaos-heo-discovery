Figure 7d: predicted EFA percentile vs descriptor compatibility score
================================================================================

Purpose
  The y-axis is a descriptor-only compatibility score.
  The x-axis remains the out-of-fold predicted EFA percentile.

Inputs

  Rows used: 493
  Feature group for EFA prediction: combined
  Number of features: 30
  Cross-validation: GroupKFold(n_splits=5)
  Model: median imputation + standard scaling + RidgeCV
  EFA used: only as the regression target and to define the true high-EFA class

Descriptor compatibility score
  S_distortion = [1-P(epsilon_bar) + 1-P(d_bar)] / 2
  S_chemistry  = [1-P(delta_r_Ghosh) + 1-P(delta_chi_Ghosh) + P(Lambda_Ghosh) + P(VEC)] / 4
  S_CHAOS      = 0.5*S_distortion + 0.5*S_chemistry
  Larger S_CHAOS indicates lower distortion, lower chemical mismatch, higher Lambda_Ghosh, and higher VEC.

Class definitions
  true high-EFA: observed EFA percentile >= 0.75
  true high descriptor compatibility score: S_CHAOS >= 0.75

Interpretation
  This panel converts EFA prediction into a descriptor-grounded screening map.
  The upper-right region corresponds to high predicted EFA and high CHAOS descriptor compatibility.
  Enrichment of true high-EFA + high-compatibility systems in this region supports using CHAOS descriptors
