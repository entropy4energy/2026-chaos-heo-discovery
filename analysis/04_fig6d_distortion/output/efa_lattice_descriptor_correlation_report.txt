EFA vs lattice-distortion descriptors: calculation report
==============================================================================

1. Purpose
   This analysis quantifies the relationship between EFA and the lattice-distortion
   descriptors used in the CHAOS manuscript.
   Only EFA and the five lattice-distortion descriptors were used.

2. Variables
   Target: EFA  -> figure label: EFA
   Descriptor: lat_distortion_misfit_mean -> figure label: $\bar{\epsilon}$
   Descriptor: lat_distortion_misfit_stdev -> figure label: $\sigma_{\epsilon}$
   Descriptor: lat_distortion_relax_distance_mean -> figure label: $\bar{d}$
   Descriptor: lat_distortion_relax_distance_stdev -> figure label: $\sigma_d$
   Descriptor: solubility_parameter -> figure label: $\delta_s$

3. Calculation procedure
   a) Read the input workbook and the specified sheet.
   b) Convert EFA and the five descriptor columns to numeric values.
   c) Drop rows with missing EFA.
   d) For each EFA–descriptor pair, compute:
      - Pearson correlation coefficient and p-value
      - Spearman correlation coefficient and p-value
      Pairwise complete observations are used for each correlation.
   e) Store the raw plot data and the correlation matrices in an Excel workbook.
   f) Use the resulting Heatmap_Pearson and Heatmap_Spearman sheets to create the figure.

8. Interpretation
   Negative EFA correlations mean that larger lattice distortion is associated with
   lower entropy-forming ability. Because EFA can be skewed, the manuscript can
   emphasize the Spearman heatmap in the main text,
   while keeping Pearson as supporting information.
